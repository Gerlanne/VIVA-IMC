# VIVA+ — Calculadora de IMC

Página web informativa de saúde e bem-estar, com uma calculadora de Índice de Massa Corporal (IMC) e a tabela de classificação para adultos.

## Funcionalidades

- Cálculo do IMC a partir de peso e altura
- Classificação automática (abaixo do peso, peso normal, sobrepeso e obesidade graus I, II e III)
- Tabela de referência de classificação
- Layout responsivo para celular e computador

## Tecnologias

- HTML5
- CSS3 (Flexbox e media queries)
- JavaScript (vanilla)

1. Clone o repositório:
   ```
   git clone https://github.com/Gerlanne/VIVA-IMC.git
   ```
2. Abra a pasta no VS Code e rode o `index.html` com a extensão **Live Server**, ou abra o arquivo direto no navegador.

## Classificação do IMC (adultos)

| Classificação      | IMC               |
|--------------------|-------------------|
| Abaixo do peso     | Abaixo de 18,5    |
| Peso normal        | 18,5 – 24,9       |
| Sobrepeso          | 25 – 29,9         |
| Obesidade grau I   | 30 – 34,9         |
| Obesidade grau II  | 35 – 39,9         |
| Obesidade grau III | Maior ou igual a 40 |
