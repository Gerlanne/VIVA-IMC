# VIVA+ — Calculadora de IMC

Página informativa de saúde e bem-estar com uma calculadora de IMC e a tabela de classificação para adultos.

## Como usar

Abra o `index.html` no navegador (ou use o Live Server no VS Code). Informe a altura em metros (ex.: 1.80) e o peso em kg, e clique em **Calcular**.

## Tecnologias

HTML, CSS e JavaScript puro.
